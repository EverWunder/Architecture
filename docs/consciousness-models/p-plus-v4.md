# P+ Model v4

> **Status:** Documented successor to the Layered Evolutionary Model v3.5 and the P+ v3.8 engine.

P+ Model v4 separates two things that earlier drafts tended to blur:

1. a layered model of how conscious cognition is constructed; and
2. an execution overlay for turning cognition into deliberate action.

## Layered evolutionary model

| Layer | Function | Representative mechanisms |
|---|---|---|
| **L1 — Core sentience** | Basic valence, arousal, bodily need, and persistence of the organism | Homeostasis, interoception, brainstem and subcortical regulation |
| **L2 — Perceptual awareness** | Binding sensory features into objects, faces, scenes, and body-centered representations | Sensory cortices, thalamocortical loops, fusiform processing |
| **L3 — Attention and salience** | Selecting which percepts, memories, or simulations receive processing priority | Salience network, attentional gain, global access |
| **L4 — Emotional regulation and embodied state** | Weighting cognition by bodily condition, affect, urgency, and controllability | Insula, limbic regulation, autonomic state, prefrontal modulation |
| **L5 — Narrative layer** | Sequencing events into a temporally extended account of self and world | Default mode network, episodic memory, language |
| **L6 — Social cognition** | Modeling other minds, norms, coalitions, reputation, and shared intention | Theory of mind, social prediction, imitation |
| **L7 — Belief and symbolic systems** | Manipulating explicit concepts, doctrines, mathematics, and abstract rules | Frontoparietal control, language, symbolic recursion |
| **L8 — Macro-context and temporal modeling** | Locating the agent inside long horizons, institutions, history, and possible futures | Hierarchical planning, scenario simulation, cultural memory |

The layers are neither rigid anatomical boxes nor a ladder climbed once. They are recurrently coupled. Lower layers constrain the energetic and sensory ground; higher layers reshape attention, interpretation, and even bodily regulation.

## Consciousness threshold

Earlier P+ drafts placed a semi-permeable threshold around the transition from attentional selection to embodied, recurrent access. The threshold is not a metaphysical border. It marks the point where content becomes sufficiently integrated, persistent, and globally usable to alter narrative, policy, and action.

A signal can therefore be:

- processed but not attended;
- attended but weakly integrated;
- globally available but poorly attributed;
- narratively incorporated yet biologically dysregulated.

This prevents the word “conscious” from swallowing several distinct mechanisms.

## Network view

P+ uses three large-scale network roles as a simplifying control diagram:

- **Default Mode Network (DMN):** autobiographical simulation, temporal narrative, and internally generated models.
- **Salience Network (SN):** detection of relevance and switching of processing priority.
- **Frontoparietal Control Network (FPCN):** rule maintenance, planning, inhibition, and deliberate manipulation.

The model expects conscious episodes to emerge from coordination among these roles rather than from a single consciousness center.

## Recursive loop

A canonical P+ loop is:

```text
Belief / symbol model (L7)
        ↓
Narrative interpretation (L5)
        ↓
Attention and salience (L3)
        ↓
Embodied valuation and regulation (L4)
        └────────→ revised narrative and belief (L5 / L7)
```

This loop explains how a belief can alter perception and bodily state, and how a bodily state can in turn alter the apparent truth and urgency of a belief.

## P+ v4 execution overlay

The execution overlay is a cockpit laid over the cognitive engine. It was added because understanding a state does not guarantee useful action.

### KarmaYogaMap

```text
Trigger → Distill → Execute → Observe → Update
```

- **Trigger:** identify the event or internal shift demanding action.
- **Distill:** reduce competing stories to the smallest testable decision.
- **Execute:** perform a bounded action rather than extending simulation indefinitely.
- **Observe:** collect external feedback.
- **Update:** revise the model and the next action.

### Execution Heatmap

The heatmap distinguishes where a plan is failing:

- unclear objective;
- excessive emotional or attentional load;
- action too large;
- missing environmental affordance;
- weak completion logging;
- no feedback loop.

The historical bottleneck identified in the model was the completion-log layer: action could occur without being registered strongly enough to update confidence and future policy.

### Low-Fidelity Playbook

The playbook deliberately lowers the resolution of an initial action. Its purpose is to escape a simulation attractor by purchasing real information cheaply.

```text
Do the smallest reversible version that can make the world answer back.
```

## Failure modes

- **L2→L5 source misfire:** perceptual or internally generated content is incorporated into narrative without adequate source checking.
- **Salience capture:** a signal dominates because it is intense, not because it is reliable or important.
- **Narrative overrule:** the story layer explains away contradictory bodily or external evidence.
- **Symbolic dissociation:** elegant abstractions become detached from sensory and operational constraints.
- **Infinite cockpit:** the execution overlay itself becomes another place to think instead of act.

## Limits

P+ v4 is a mesoscopic design model. It compresses many neural mechanisms into useful functional layers. It is not a complete brain atlas, a diagnostic instrument, or proof that reproducing the same functions in software reproduces subjective experience.
